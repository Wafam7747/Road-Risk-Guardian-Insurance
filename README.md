# Road Risk Guardian Insurance — Data Science Bootcamp

Data cleaning and exploratory analysis of 900K+ road-incident reports for a vehicle insurance company, with an interactive dashboard for exploring accident patterns by time, location, weather, and severity.

🔗 **Live dashboard:** https://wafaamoha.github.io/Road-Risk-Guardian-Insurance/road_risk_dashboard.html

## Files
- `Case_Study_Wafa_v2.ipynb` — data cleaning and analysis notebook
- `road_risk_dashboard.html` — interactive dashboard
- ## Tech stack
- **Python** — Pandas, NumPy for data cleaning and analysis
- **Matplotlib** — static visualizations in the notebook
- **HTML/CSS/JavaScript + Chart.js** — interactive dashboard

## Key insights
- Accident volume peaks in Fall and Winter
- Most accidents occur in clear weather, not severe conditions
- Rush-hour peaks (7–8 AM, 4–5 PM) are a weekday pattern — weekends are flatter
- High-volume cities aren't always the highest-severity ones
